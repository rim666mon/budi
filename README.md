# 🔔 budi

**Минималистичный будильник-напоминание для Fedora на базе `at` + `notify-send` + Telegram.**

Простой способ не забыть о важном: одна команда в терминале или сообщение в Telegram — и напоминание сработает в нужный момент.

---

## ✨ Возможности

- ⏰ **Абсолютное и относительное время** — `budi +30` или `budi 19:35 2026-09-23`
- 🔁 **Повторы** — сколько раз и с каким интервалом напомнить
- 🚨 **Urgent-уведомления** — не исчезают сами, пока не кликнешь
- 📱 **Telegram** — уведомления в чат и управление ботом
- 💻 **Гибкость** — только рабочий стол (`-pc`) или только Telegram (`-tg`)
- 🎨 **Цветной список** — `budilist` с датой, счётчиком и историей
- 🧠 **Проверка дубликатов** — предупредит, если на это время уже что-то есть
- 📝 **Логирование** — все создания и удаления в `~/.budi.log`

## 📦 Установка

### Требования

- Fedora (или другой Linux с `systemd`, `at`, `notify-send`)
- `at`, `libnotify`, `curl`, `python3`

```bash
sudo dnf install at libnotify curl python3
```

### Клонирование и установка

```bash
git clone git@github.com:rim666mon/budi.git ~/projects/budi_project
cd ~/projects/budi_project
./install.sh
```

`install.sh` создаст симлинки в `/usr/local/bin/` и включит `atd` в автозапуск.

### Telegram (опционально)

1. Создайте бота у `@BotFather` в Telegram → получите **токен**.
2. Напишите боту любое сообщение, узнайте `chat_id` через `@userinfobot`.
3. Скопируйте пример конфига:

```bash
cp conf/budi-telegram.conf.example ~/.budi-telegram.conf
chmod 600 ~/.budi-telegram.conf
vim ~/.budi-telegram.conf
```

```ini
TG_TOKEN="123456:ABC-DEF..."
TG_CHAT="123456789"
```

4. Установите `budiwatch` для управления ботом:

```bash
mkdir -p ~/.config/systemd/user
cp conf/budiwatch.service.example ~/.config/systemd/user/budiwatch.service
systemctl --user daemon-reload
systemctl --user enable --now budiwatch.service
```

## 🚀 Использование

### Создание напоминания

```bash
budi +30 позвонить маме                   # через 30 минут
budi +2h бэкап                            # через 2 часа
budi 19:35 2026-09-23 203 починить телефонию   # на конкретное время
```

### Опции

| Флаг | Описание |
|---|---|
| `-r N` | число повторов (по умолчанию `0`) |
| `-i N` | интервал между повторами в секундах (по умолчанию `60`) |
| `-u` | urgent: уведомление не исчезает само |
| `-tg` | только Telegram, без окна на рабочем столе |
| `-pc` | только рабочий стол, без Telegram |

```bash
budi +2h бэкап -r 2 -i 120 -u       # 3 уведомления с интервалом 2 мин
budi +30 проверить сервер -tg        # только в Telegram
budi +30 попить воды -pc -u          # только на рабочем столе
```

### ID в сообщении

Если после времени идёт число, оно считается ID:

```bash
budi +30 203 позвонить клиенту
# Уведомление: "203 позвонить клиенту"
```

### Управление

```bash
budilist      # список задач + счётчик + история
budidel 7     # удалить задачу №7
budiinfo      # полная справка
```

### Telegram-бот

| Команда | Что делает |
|---|---|
| `/start`, `/help` | справка по формату |
| `/list` | активные напоминания |
| `/info` | полная справка `budi` |
| `/log` | последние 10 записей лога |
| `/del N` | удалить задачу N |
| `/ping` | проверка связи |

Можно создавать задачи прямо из Telegram:

```
+30 позвонить маме
19:35 2026-09-23 203 починить телефонию
+2h бэкап -r 2 -i 120
```

## ⚙️ Как это работает

1. `budi` формирует команду `notify-send` (и/или `curl` в Telegram).
2. Планирует через `at` — системный планировщик одноразовых задач.
3. Демон `atd` следит за очередью и выполняет задачи в нужный момент.
4. `budiwatch` — отдельный сервис `systemd --user`, который читает сообщения бота и создаёт задачи от вашего имени.

**Задачи сохраняются после выключения ПК** и выполняются при следующем включении, даже если время уже прошло.

## 🔐 Безопасность

- `~/.budi-telegram.conf` **не коммитится** в git (в `.gitignore`).
- В репозитории только пример с заглушкой.
- `budiwatch` игнорирует сообщения не от вашего `chat_id`.
- Если токен утёк — перевыпустите его у `@BotFather` (`/revoke`).

## 🛠️ Диагностика

```bash
# Работает ли atd
systemctl status atd

# Работает ли budiwatch
systemctl --user status budiwatch.service

# Что происходит в Telegram-сервисе
journalctl --user -u budiwatch -f

# Очередь задач
atq

# Содержимое конкретной задачи
at -c 5

# Лог budi
tail -n 20 ~/.budi.log
```
